# ChatX — Number Baseball

Unreal Engine 5.8.2 C++ 숫자 야구 멀티플레이 과제 프로젝트

##  구조

| 파일 쌍 | 역할 |
|---|---|
| NBNumberBaseballLibrary | 무상태 정답 생성, 입력 검사, S/B/OUT 계산 |
| NBPlayerState | 플레이어별 사용 횟수 0 ~ 3 / 최대 3, 서버 변경 및 전체 복제 |
| NBGameState | 라운드·턴·현재 플레이어·마감 서버 시각·결과 복제, 전체 메시지 NetMulticast |
| NBGameModeBase | 서버 정답 보관, 참가 순서, 판정, 시간초과, 승리/무승부, 재시작 |
| NBPlayerController | 로컬 입력 → 소유 Server RPC → GameMode, 개인 오류 Client RPC, UI 생성 |
| NBChatInput | C++ WidgetTree, 채팅 100줄, 결과 배너, 플레이어별 횟수, 턴·시간 UI |

헤더는 `Source/ChatX/Public`, 구현은 `Private`에 있다. 라이브러리는 `UBlueprintFunctionLibrary`를 상속한 **프로젝트 모듈 내부 C++ 정적 함수 집합**이다. GameMode가 이 라이브러리를 호출해 서버에서 판정한다.

## 규칙과 네트워크

- 정답은 1 ~ 9 중 중복 없는 3자리다. GameMode private 문자열에만 보관하고 새 라운드마다 서버 로그에 출력한다. 복제 프로퍼티나 공개 상태에 정답을 넣지 않는다. 제출된 추측은 일반 판정 메시지로 공개된다.
- 정확히 3개의 ASCII 숫자 1..9만 허용한다. 0, 중복, 공백, 문자, 전각 숫자, 잘못된 길이는 거부하며 추측 입력을 자동 Trim하지 않는다. 메시지는 최대 256자다.
- 자리까지 같으면 S, 다른 자리에 있으면 B, 일치 숫자가 없으면 OUT이다. 예: 정답 386에서 127=OUT, 167=0S1B, 368=1S2B, 386=3S0B.
- `[현재/최대]`는 **사용한 횟수**다. 유효 추측 또는 시간초과에만 1회 소모한다. 각 플레이어 최대 3회이고 무효 추측은 차감하지 않는다. 시간이 이미 끝난 요청은 시간초과 규칙이 우선이다.
- 참가 순서대로 30초 턴을 부여한다. `bHasSubmittedThisTurn`과 `bTurnResolved`가 같은 턴의 중복 처리/시간초과 경합을 막는다. 요청의 TurnId, 현재 플레이어, 서버 마감 시각을 검사하며 TurnId는 라운드가 바뀌어도 증가한다.
- 화면 시간은 `GetServerWorldTimeSeconds()`와 복제된 마감 시각의 차이다. 프레임·네트워크 지연 때문에 화면 정수 초가 잠시 다를 수 있다. 클라이언트가 횟수나 판정을 예측해 변경하지 않는다.
- 3S면 승자 이름을, 전원 3회 소진이면 무승부를 공지한다. 결과 배너를 3초 표시하고 새 정답·0회로 시작한다. 결과 표시 중 추측은 거부한다.
- 중도 참가자는 0/3으로 순서 끝에 추가된다. 현재 참가자가 퇴장하면 차감 없이 다음 참가자로 이동한다. 서버가 비면 타이머를 정리하고 대기한다.
- `/say 내용`은 턴·횟수와 무관한 일반 채팅이다. 전체 채팅/판정/공지의 전달 경로는 GameState NetMulticast 한 곳이고, 개인 오류는 발신자의 Client RPC로만 전달한다.
